# Changelog

## 0.1.0

Initial distribution of the OMARO reference dataset and tooling, with ontology
and validation schema 0.1.0.

- 643 Hornbostel–Sachs classifications, 2,724 resolved instrument concepts and
  five unresolved source references, derived from MIMO.
- Preferred and alternative labels in 13 languages, with preserved source
  identifiers and assertion-scoped SKOS-XL labels.
- Qualified classification, relation, label and note assertions; explicit
  applicability, provenance and review semantics.
- Organological targets, assessment methods, evidence and publication controls.
- JSONL, CSV, RDF, SQLite and offline knowledge exports, with validation schemas,
  a browser, worked examples and a field guide.
- Deterministic archives, checksums, DCAT, DQV and RO-Crate metadata.

The reference dataset contains source-transcribed assertions. It does not
supply empirical organological assessments or community review decisions.
