# Support

- Use [GitHub Issues](https://github.com/modavis-project/omaro/issues)
  for reproducible defects, data corrections, and documentation problems.
- Use [GitHub Discussions](https://github.com/modavis-project/omaro/discussions)
  for implementation and modelling questions when Discussions is enabled.
- Use GitHub private vulnerability reporting for security or credential issues;
  see `SECURITY.md`.
- Use the private maintainer contact route for sensitive reviewer information,
  community correspondence, withdrawal requests, or cultural protocols.
